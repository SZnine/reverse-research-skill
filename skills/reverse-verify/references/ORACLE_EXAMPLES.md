# Oracle Examples

## UI alignment

Claim: the patched screen no longer clips a label. The source of truth is visual layout on the target device/configuration. A user screenshot or direct observation is valid. Database inspection would be irrelevant over-validation.

## UI says “saved”

Claim: the value persists. The toast is not the oracle. Inspect the persisted state and repeat after reload/restart; include a control where the value is not changed.

## Hook loaded

Claim: the instrumentation process started. The load message may support that narrow claim. It does not show that the target method was resolved, hit, or controlled behavior.

## Protocol header parsed

Claim: a file imports successfully. Header/decryption success is upstream only. The oracle is the business-layer object/result or accepted roundtrip.

## Patched APK installs

Claim: packaging/signing/install baseline works. Installation supports that claim. It does not establish that the intended app behavior changed or persists.
